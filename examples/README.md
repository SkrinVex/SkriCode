# 📦 Готовые проекты SkriPts

Коллекция готовых проектов для импорта в SkriPts.

## 📁 Формат файлов

Проекты SkriPts сохраняются в формате `.skripts` — это минифицированный JSON в одну строку.

**Пример структуры:**
```json
{
  "appVersion": "1.4",
  "formatVersion": 2,
  "project": {
    "id": "project-id",
    "name": "Название проекта",
    "scenes": [...],
    "globalVars": [...],
    "sprites": [...]
  }
}
```

## 🎮 Список проектов

### 1. Bouncing Balls (Прыгающие шарики)
**Файл:** `bouncing-balls.skripts`

**Описание:** Демонстрация физического движка. Тапай по экрану чтобы создавать шарики, которые падают и отскакивают от пола.

**Что демонстрирует:**
- ✅ Физика с гравитацией
- ✅ Упругость (bounciness)
- ✅ Статические объекты (пол)
- ✅ Обработка тап-событий
- ✅ Динамическое создание объектов
- ✅ Работа с переменными
- ✅ Случайные значения (random)

**Как использовать:**
1. Открой SkriPts
2. Нажми "Импорт проекта"
3. Выбери файл `bouncing-balls.json`
4. Запусти симуляцию
5. Тапай по экрану чтобы создавать шарики!

### 2. Pong Game (Понг)
**Файл:** `pong-game.skripts`

**Описание:** Классическая игра Pong для двух игроков. Управляй ракетками джойстиками и отбивай мяч!

**Что демонстрирует:**
- ✅ Джойстики для управления
- ✅ Физика без гравитации
- ✅ Коллизии и отскоки
- ✅ Система счета
- ✅ Условия (if_block)
- ✅ Изменение свойств объектов (sim_modify)
- ✅ Текстовые объекты
- ✅ Математические операции

**Как играть:**
1. Импортируй проект
2. Запусти симуляцию
3. Игрок 1 (синий) — левый джойстик
4. Игрок 2 (красный) — правый джойстик
5. Отбивай мяч и набирай очки!

**Правила:**
- Мяч отскакивает от ракеток и верхней/нижней границы
- Если мяч вышел за левую границу — очко игроку 2
- Если мяч вышел за правую границу — очко игроку 1
- Мяч возвращается в центр после каждого очка

## 📥 Как импортировать проекты

### Способ 1: Через файловый менеджер
1. Скопируй `.skripts` файл на устройство
2. Открой SkriPts
3. Главный экран → "Импорт проекта"
4. Выбери файл

### Способ 2: Через ADB (для разработчиков)
```bash
adb push bouncing-balls.skripts /sdcard/Download/
adb push pong-game.skripts /sdcard/Download/
```

### Способ 3: Открыть напрямую
```bash
adb shell am start -a android.intent.action.VIEW \
  -d "file:///sdcard/Download/bouncing-balls.skripts" \
  -t "application/octet-stream"
```

## 🛠️ Утилита project_tool.py

Для работы с файлами проектов есть утилита в папке `tools/`:

### Форматирование (для чтения)
```bash
python tools/project_tool.py prettify bouncing-balls.skripts
# Создаст bouncing-balls.pretty.json
```

### Минификация (для импорта)
```bash
python tools/project_tool.py minify my-project.json
# Создаст my-project.skripts
```

### Информация о проекте
```bash
python tools/project_tool.py info bouncing-balls.skripts
```


## 🛠️ Модификация проектов

Все проекты можно свободно изменять:

1. **Измени цвета:**
   - Найди блоки `sim_create`
   - Измени параметр `color`

2. **Измени физику:**
   - Найди блоки `sim_physics`
   - Измени `gravity`, `bounciness`, `mass`

3. **Добавь новые объекты:**
   - Скопируй существующие блоки
   - Измени параметры

4. **Измени управление:**
   - Измени параметр `speed` у джойстиков
   - Добавь новые джойстики

## 💡 Советы по созданию своих проектов

### Структура проекта
```
Проект
├── Сцена 1
│   ├── Скрипт SETUP (инициализация)
│   ├── Скрипт TICK (игровой цикл)
│   ├── Скрипт TAP (обработка тапов)
│   └── Скрипт COLLISION (коллизии)
├── Переменные (счет, состояние)
└── Спрайты (текстуры)
```

### Лучшие практики

1. **Используй переменные для счетчиков:**
   ```
   set_var: ballCount = 0
   math: ballCount = $ballCount + 1
   ```

2. **Именуй объекты осмысленно:**
   - ✅ `player`, `enemy1`, `wall_left`
   - ❌ `obj1`, `rect2`, `thing`

3. **Группируй объекты тегами:**
   ```
   set_tag: object = player, tag = #hero
   set_tag: object = enemy1, tag = #enemies
   ```

4. **Используй выражения для динамики:**
   ```
   x = $screenWidth / 2
   y = sin($time * 0.1) * 100 + 300
   color = random(0, 255)
   ```

5. **Оптимизируй физику:**
   - Делай статичными объекты которые не двигаются
   - Отключай физику для декоративных объектов
   - Используй `visible = false` для скрытых объектов
